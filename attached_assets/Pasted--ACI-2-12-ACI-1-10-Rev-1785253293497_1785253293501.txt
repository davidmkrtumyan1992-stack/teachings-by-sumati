Мне нужно дозаполнить курсы ACI 2–12 видео-контентом. ACI 1 уже полностью работает (10 классов + Review Class, видео EN/RU, переключение языка) — используй его как образец паттерна: найди, где и как заведены данные и страницы классов для aci-1 (компонент страницы класса, роутинг /aci-courses/[course]/[class], структуру данных, откуда берутся videoEN/videoRU), и повтори тот же подход для ACI 2–12. Не трогай и не переписывай данные/логику ACI 1 — она уже боевая.

Я приложил файл data/aci-videos-2-12.json — массив из 11 курсов (aci-2 … aci-12). Формат каждого курса:


{
  "course": "aci-2",
  "courseNumber": 2,
  "title": "ACI 2 - Buddhist Refuge (Aug 28 - Oct 5, 2023)",
  "playlistEN": "https://www.youtube.com/playlist?list=...",
  "playlistRU": "https://www.youtube.com/playlist?list=...",
  "classes": [
    {
      "classNumber": 1,
      "isReview": false,
      "videoEN": null,
      "videoRU": "https://youtu.be/OMoK11SOHQE",
      "status": "ready"
    },
    ...
    { "classNumber": null, "isReview": true, "videoEN": "...", "videoRU": "...", "status": "ready" }
  ]
}
Правила подключения:

Заполняй страницы классов (/aci-courses/aci-{N}/class-{M} и Review Class) данными из этого файла — так же, как это устроено для ACI 1, чтобы вместо "Class not found" открывалось реальное видео с переключателем EN/RU.
Если videoEN или videoRU равно null (запись на этом языке не существует) — не ломай переключатель языка: просто не показывай отсутствующую версию (например, скрой кнопку/иконку языка, для которого записи нет, или покажи плейсхолдер "запись недоступна"), но вторую версию показывай нормально. Такое есть у ACI 2 Class 1 (нет EN) и у ACI 10 Review Class (нет ни EN, ни RU вообще — здесь помести дефолтный вид, как будто видео ещё не опубликовано, но саму страницу класса не убирай).
Классы со "status": "not_recorded_yet" (это только в ACI 12, классы 4–10 и Review) не показывай как рабочие — либо не создавай для них страницу вообще (пусть работает текущее поведение по умолчанию), либо покажи явный статус "Recording coming soon" / "Запись появится позже" вместо плеера. Не выдумывай видео для них.
На странице курса (/aci-courses/aci-{N}) списки классов уже отображаются (там уже все 18 карточек курсов и переходы на классы) — просто убедись, что теперь ссылки на классы 2–12 ведут на реально работающие страницы вместо 404/"Class not found".
Название title можно использовать для хедера страницы курса, если сейчас там дефолтный текст — но не обязательно, если уже есть отдельный точный список названий курсов на сайте (я видел, что в /aci-courses уже стоят точные официальные названия — не перезаписывай их этим полем, если оно менее точное).
Ещё один мелкий, не связанный с видео фикс раз уж будешь в этих файлах: кнопка "Transcript" на странице класса сейчас ничего не делает (нет ссылки/обработчика). Транскриптов пока не существует ни для одного класса — убери эту кнопку полностью (для всех курсов, не только 2–12), чтобы не было мёртвого UI. Когда транскрипты появятся, кнопку вернём отдельным шагом.
