Нужно подключить реальные PDF-материалы курса вместо декоративных карточек "Student Notes / Reading / Homework" на странице класса (сейчас у всех одинаковый фейковый размер "200 KB" и кнопки никуда не ведут).

Я загрузил папку public/materials/ с PDF-файлами и файлом public/materials/manifest.json, который для каждого курса даёт имена файлов на английском и русском:


{
  "aci-2": {
    "en": { "notes": "aci-2-en-notes.pdf", "reading": "aci-2-en-reading.pdf", "homework": "aci-2-en-homework.pdf" },
    "ru": { "notes": "aci-2-ru-notes.pdf", "reading": "aci-2-ru-reading.pdf", "homework": "aci-2-ru-homework.pdf" }
  },
  ...
}
Важно: это материалы на уровне курса, не на уровне класса — один и тот же набор из 3 PDF (Notes/Reading/Homework) должен использоваться для ВСЕХ классов внутри одного курса (Class 1, Class 2, ..., Review Class у ACI 2 все ссылаются на одни и те же aci-2-en-notes.pdf / aci-2-en-reading.pdf / aci-2-en-homework.pdf для английской версии, и аналогично для русской). Это подтверждено структурой исходных файлов на Google Диске — так и должно быть, это не ошибка.

Правила подключения:

Три карточки "Student Notes" / "Reading" / "Homework" на странице класса должны вести на notes / reading / homework из manifest.json для соответствующего курса и текущего выбранного языка (EN/RU) — переключение языка на странице класса должно менять, на какой PDF ведут кнопки, точно так же как оно уже меняет видео.
Покажи реальный размер файла вместо фейковых "200 KB" (можно взять из файловой системы при сборке, или просто убрать цифру размера, если это сложно сделать статически).
Особый случай — ACI 1, русская версия Reading: у ACI 1 в manifest.json для ru есть только notes и homework, поля reading нет — русского Reading PDF для этого курса не существует в источниках. Когда выбран русский язык на страницах классов ACI 1, карточка Reading должна либо скрываться, либо показывать "недоступно на русском" — не бери английский файл вместо неё и не ломай верстку.
ACI 6 временно без русских материалов: для aci-6 в manifest.json есть только en, поля ru нет вообще — я нашёл, что русские файлы для этого курса на Google Диске были ошибочно подписаны как принадлежащие ACI 4 (файлы буквально побайтово идентичны файлам ACI 4, я это проверил). Настоящих русских материалов для ACI 6 пока не существует, они появятся позже. Пока для ACI 6 на русском языке карточки Notes/Reading/Homework должны вести на английские версии либо показывать "скоро добавим" — не показывай пустые/битые ссылки и не выдавай материалы ACI 4 за материалы ACI 6.
